High-Level Understanding: Regulated Decision Intelligence

Why Black-Box Generative AI Fails in Regulated Healthcare & How the Veridict Triad Solves It.

⚖️

The Regulatory Crisis

In healthcare utilization management, prior authorization, and claims adjudication, decisions affect human health and millions of dollars in coverage. Federal and state authorities enforce strict statutory frameworks:

  • CMS-0057-F Interoperability & Prior Auth Rule: Mandates specific, auditable denial reasons and strict 72-hour expedited turnarounds.
  • ERISA § 503 (29 CFR 2560.503-1): Requires full and fair review, identification of specific plan rules/protocols, and mandatory human physician appeal rights.
  • Congressional Inquiries: Scrutiny over black-box denial algorithms (e.g. nH Predict lawsuits) where automated tools denied care without verifiable clinical grounding.
🛡️

The Veridict Triad Pattern

Rather than querying a single monolithic LLM prompt, Veridict decouples reasoning into an adversarial triad with deterministic mathematical guardrails:

  • Proposer (Clinical Specialist): Performs evidence mapping, evaluates criteria thresholds, and proposes an evidence-grounded action.
  • Critic (Adversarial Auditor): Actively looks for reasons why the proposal is wrong or unsafe (hallucinated citations, missing contraindications, step therapy shortfalls).
  • Judge (Chief Medical Officer): Adjudicates consensus, computes divergence, enforces deterministic safety overrides, and determines human routing.

Low-Level Architecture & Technical Specifications

Data Contracts, Computable AST Evaluation, Character Offset Grounding, and Cryptographic Merkle Lineage.

1. Computable Policy Schema (AST Model)

Policies are defined as strongly typed Pydantic models containing formal criteria predicates:

class ClinicalCriterion(BaseModel):
    criterion_id: str             # e.g. CRIT-GLP1-BMI-HIGH
    criterion_type: CriterionType # INCLUSION | EXCLUSION | STEP_THERAPY
    field_name: str               # e.g. "bmi"
    rule_operator: str            # ">=", "<=", "==", "in"
    threshold: Any                # 30.0
    unit: Optional[str]           # "kg/m2"
    lookback_days: Optional[int]  # 90 days max age
    is_mandatory: bool            # True

Logical groups evaluate with ALL_OF, ANY_OF, or AT_LEAST_N semantics, separating clinical logic from arbitrary text prompts.

2. Zero-Tolerance Citation Grounding

Every criterion claim must be anchored to verbatim source spans:

def verify_citation(citation: Citation, raw_text: str):
    # 1. Exact string search
    idx = raw_text.find(citation.verbatim_quote)
    if idx != -1:
        citation.start_char = idx
        citation.end_char = idx + len(citation.verbatim_quote)
        citation.is_verified = True
    # 2. Rejection on hallucination
    else:
        citation.is_verified = False
        citation.verification_error = "Quote not found verbatim"

If any citation is unverified, the Critic triggers a BLOCKER, guaranteeing zero-hallucination defense.

3. Cryptographic Hash Chain & Merkle DAG

Every decision generates a 5-stage sequential SHA-256 hash chain:

H(Node_i) = SHA256( CanonicalJSON(Payload_i) + ":" + H(Node_{i-1}) )
MerkleRoot = PairwiseHashTree( [H(Node_1), ..., H(Node_5)] )

Any bit change in patient data, proposer output, or critic findings immediately breaks the parent hash and invalidates the Merkle root.

4. Deterministic Safety Override Protocol

The Judge employs a hard statutory override rule:

if critic.severity_max == ChallengeSeverity.BLOCKER:
    # Autonomous safety override overturns approval
    final_det = Determination.DENY
    status = ConsensusStatus.SAFETY_OVERRIDE_ENFORCED
    hitl_required = True
    hitl_reason = "Mandatory Medical Director signature for safety override"

This guarantees that a rogue proposer cannot push through a contraindicated medication.
